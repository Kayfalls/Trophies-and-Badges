# Trophies & Badges 🏆

A client-facing e-commerce web app built for a local awards shop in Johannesburg. Customers can browse products by category and subcategory, create an account, and get in touch to place orders.

## Live Demo

[View the live site](https://trophiesandbadges.vercel.app/) <!-- replace with your actual Vercel URL -->

## Features

- Product catalogue with category and subcategory filtering
- Customer authentication (sign up / log in)
- Responsive design across mobile and desktop
- Real-time data loading via Firebase
- Clean, client-friendly UI

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend/Database:** Firebase (Firestore + Auth)
- **Deployment:** Vercel

## Getting Started

Clone the repo and open `index.html`, or visit the live Vercel deployment.

```bash
git clone https://github.com/Kayfalls/trophies-and-badges.git
cd trophies-and-badges
open index.html
```

> **Note:** You'll need to set up your own Firebase project and replace the config in `js/main.js` with your credentials.
